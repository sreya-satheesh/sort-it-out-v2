# Sort It Out!

An interactive sorting visualizer built around three classic algorithms.

## Features

- Bubble Sort, Selection Sort, and Insertion Sort.
- Step-by-step comparisons and movements.
- Sort your own numbers or letters.
- Play, pause, and restart controls.
- Time and space complexity.
